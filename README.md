# Job Connect

Job Connect is a web-based job portal that connects job seekers and employers.

## Main Features

- User registration and login
- Job seeker profile
- Employer dashboard
- Create and manage job postings
- Search and view jobs
- Apply for jobs
- Manage job applications

## Technologies Used

- Frontend: React.js
- Backend: Django REST Framework
- Authentication: Django Auth / SimpleJWT
- Database: MySQL 8
- ORM: Django ORM
- API Testing: PowerShell / REST API requests
- Testing: Pytest
- Development Environment: Visual Studio Code
